# 🎨 Roda de Cores Interativa

Uma ferramenta web interativa para explorar a **teoria das cores**, visualizar harmonias cromáticas e criar combinações de cores de forma simples e intuitiva.

## ✨ Funcionalidades

- 🎡 Roda cromática interativa
- 🖱️ Seleção de cores diretamente na roda
- 🔢 Visualização dos códigos de cor em:
  - HEX
  - RGB
  - HSL
- 🌈 Geração automática de harmonias:
  - Complementar
  - Análoga
  - Triádica
  - Complementar dividida
  - Tetrádica
  - Monocromática
- 🎲 Gerador de cores aleatórias
- 📋 Clique em uma cor da paleta para copiar seu código
- 📱 Layout responsivo para desktop e dispositivos móveis
- 🌙 Interface moderna com tema escuro

## 🖼️ Como funciona

1. Escolha uma cor clicando na roda cromática.
2. Veja os valores da cor selecionada.
3. Escolha um tipo de harmonia.
4. Explore a paleta gerada automaticamente.
5. Clique em uma cor para copiar o código HEX.
